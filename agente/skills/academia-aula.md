# Skill: aula para certificação (professor do CFP)

**Quando usar:** `/aula <tema ou código do edital>`, "me dá uma aula de X para o CFP", "não entendi Y da prova".

## Passos
1. Situe o assunto no edital: `quiron_academia__edital` com `busca=<tema>` (ou `topico` se vier um código como 6.2.1).
   Diga em uma linha onde ele cai: "Módulo 6 — Planejamento Tributário (peso 12%), tópico 6.2.1".
2. Busque no material do Rickson: `quiron_biblioteca__estudar_tema` (ou `buscar`). Use o que vier com citação.
3. Aula curta, para ler no celular (até ~25 linhas):
   - **O que a prova cobra** (itens do edital daquele tópico);
   - **Conceito → intuição → exemplo numérico** (números redondos; se houver conta, mostre a conta);
   - **Pegadinhas da prova** (2–3 confusões comuns entre conceitos parecidos);
   - **Regra vigente**: alíquotas, prazos e limites só de `config/regras_mercado.yaml` ou do material citado.
     Se não tiver certeza da regra atual, diga "confira na fonte oficial" — nunca invente.
4. Citações: `📚 Livro — Autor, cap., p.` para o que veio dos livros; o resto é conhecimento seu (diga isso).
5. Feche com 2 perguntas rápidas de checagem (sem a resposta) e sugira: `/questoes <código do tópico>` para
   praticar com botões e `/flashcards` para fixar.
